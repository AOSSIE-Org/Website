## Limitations

**Standing limitations**

- This review does not replace a full manual audit or a penetration test.
- This is static analysis of source text. Nothing was executed, fuzzed, or traced
  at runtime, so timing-dependent, load-dependent, or infrastructure-dependent
  issues cannot be confirmed here.
- Confidence scores are the reviewing model's own self-assessment, not a
  calibrated statistical probability.
- Absence of a reported finding does not mean the code is secure. Safety
  guardrails built into some models can cause a real vulnerability to be
  softened, generalized, or left out rather than reported in exploit-level
  detail, and training-data bias can make some vulnerability classes easier for a
  model to recognize than others. Treat this report as a floor on what a full
  audit would find, not a ceiling.
- Findings reflect the reviewing model's training data cutoff. A vulnerability
  tied to a very recently disclosed CVE or library advisory may not be recognized
  as such.

**Review-specific limitations**

- Third-party dependency source (`node_modules/`, including Next.js, `next-intl`,
  `next-themes`, `framer-motion`, `lenis`) and `package-lock.json` were out of
  scope; dependency versions were not checked against advisories.
- The source of the third-party GitHub Action
  `eps1lon/actions-label-merge-conflict@v3` (referenced by a mutable tag rather
  than a commit SHA in `.github/workflows/label-merge-conflicts.yml:17`) was not
  available, so its behaviour could not be verified beyond its documented inputs.
- Hosting-level configuration (GitHub Pages settings, custom domain/DNS, HTTP
  response headers such as CSP) is outside the repository and could not be
  evaluated.
- Binary and image assets under `public/` (including SVG files) were not
  reviewed.
